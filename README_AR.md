# محرك أبو العسل الكمي

محرك API مستقل أولي لمنصة AbuAlAsal Quant Fusion AI PRO.

## النشر على Render
1. ارفع هذه الملفات إلى مستودع GitHub جديد.
2. في Render اختر «جديد» ثم «خدمة ويب» واربط المستودع.
3. اترك مجلد الجذر فارغًا إذا كانت الملفات في جذر المستودع.
4. أمر البناء: `pip install -r requirements.txt`
5. أمر التشغيل: `uvicorn app:app --host 0.0.0.0 --port $PORT`
6. مسار فحص الصحة: `/health`
7. بعد النشر اختبر `/health` ثم `/api/v1/market/ticker?symbol=BTCUSDT`.

## حدود الإصدار
- بيانات Binance هنا للعملات الرقمية المدعومة فقط، وليست أسعار الذهب أو الفوركس.
- إليوت وجان 9 وفيبوناتشي والدورات الزمنية غير محسوبة حتى تنفيذ قواعد قابلة للاختبار.
- لا توجد احتمالات نجاح مختلقة ولا تنفيذ أوامر تداول.
- الخطة المجانية قد تدخل وضع السكون.
